## 4. Nodemailer Email Service & Backend Auth Endpoints

- **[mail.service.ts](file:///d:/Code/capstone/api/src/services/mail.service.ts)**
  - Built a responsive HTML email template featuring BQ logo branding (`B` black + `Q` `#a60b0b`), card container, CTA button ("RESET PASSWORD"), and 1-hour expiration notice.
  - Implemented automatic Ethereal Email fallback with clickable `https://ethereal.email/message/...` preview links logged in terminal when live SMTP environment variables are unconfigured.
- **[auth.services.ts](file:///d:/Code/capstone/api/src/services/auth.services.ts)**, **[auth.controller.ts](file:///d:/Code/capstone/api/src/controller/auth.controller.ts)**, **[auth.routes.ts](file:///d:/Code/capstone/api/src/routes/auth.routes.ts)**:
  - `POST /auth/forgot-password`: Validates email, generates 1-hour signed JWT reset token, and triggers email service.
  - `POST /auth/reset-password`: Verifies JWT reset token, hashes password using Argon2, and updates user credentials in MongoDB via Prisma.
